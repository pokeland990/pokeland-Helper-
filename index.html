How to install
1
Download the client
Get the APK from pokelandlegends.com. On Android allow install from unknown sources when prompted.
2
Let resources unpack
First launch downloads the asset packs — use Wi-Fi and keep the app open.
3
Pick a server
New servers reset rankings — check the Server tab for the next opening time.
4
Bind your account
Sign in with Facebook or your Jodo account so progress survives a reinstall.

Day one tips

Save diamonds for the first legendary rotation. Claim all three daily Vit Gift windows — friendship vit is the slowest resource in the game. Weather boosts follow Vietnam time (ICT), so check the Weather tab before you plan a catch run.
